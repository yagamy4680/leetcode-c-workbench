# 1480. Running Sum of 1d Array

[Original problem](https://leetcode.com/problems/running-sum-of-1d-array/description/)

Return an array whose element i is the sum of nums[0] through nums[i].

Constraints: 1–1000 elements; each value from -10^6 to 10^6.

Input ownership: the driver owns nums. The returned array can be newly allocated or exactly nums; the driver releases it once. Set returnSize.

Examples are in `tests.json`. The starter solution intentionally needs implementation.
