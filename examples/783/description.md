# 783. Minimum Distance Between BST Nodes

[Original problem](https://leetcode.com/problems/minimum-distance-between-bst-nodes/description/)

Return the smallest difference between any two node values in the given BST.

Constraints: 2–100 nodes; values from 0 to 100000. Input uses LeetCode level-order encoding with null slots.

Input nodes belong to the driver; do not free them. This URL is problem 783. Problem 530 is equivalent but uses getMinimumDifference.

Examples are in `tests.json`. The starter solution intentionally needs implementation.
