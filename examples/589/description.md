# 589. N-ary Tree Preorder Traversal

[Original problem](https://leetcode.com/problems/n-ary-tree-preorder-traversal/description/)

Return node values in preorder: visit the node, then its children in order.

Input uses LeetCode level-order encoding: root, null, root child group, null, next child group, and so on. Empty child groups require their separator.

Constraints: 0–10000 nodes; height at most 1000.

The driver owns input nodes. Return a newly allocated array and set returnSize; the driver frees the result.

Examples are in `tests.json`. The starter solution intentionally needs implementation.
